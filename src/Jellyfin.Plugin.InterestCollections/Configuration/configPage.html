Processing

Episodes are off by default: per-episode interests add a lot of metadata noise for very little browsing value.
Jellyfin announces new items before their provider ids are filled in, so the plugin waits for a quiet period first.
Leave empty to process every library.

Tagging

Stops a later metadata refresh from discarding the interests, at the cost of also blocking other sources from editing tags.

Collections

About the IMDb provider

                    

                        IMDb's public endpoint states that public, commercial or otherwise non-private
                        use of its data is not permitted, and that only limited non-commercial use is
                        allowed. Using it to tag your own self-hosted library falls inside that limit;
                        redistributing the results does not. Answers are cached for 30 days by default
                        and requests are throttled. If you would rather avoid the question entirely,
                        switch the provider to TMDb Keywords or to the offline local rules.
